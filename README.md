## What it does

- Live SVG preview with full control of size, radius, colours, gradients, fonts and outline
- Left and right text, drag-and-drop text position, optional border
- Built-in icon library plus custom SVG icon upload
- Presets, brand kits and packs (Developer Profile, React, Python, Docker, CI/CD and more)
- Bulk badges with Shields.io-compatible Markdown
- Export: copy SVG, download SVG, download PNG, copy README Markdown or HTML
- Build diagnostics for Shields.io standard checks, safe SVG text escaping, light and dark themes
- Local-first: settings are saved in your browser only

## Using it

Open the app, design a badge, then copy the Markdown snippet into your README or download the file. There is nothing to install.
